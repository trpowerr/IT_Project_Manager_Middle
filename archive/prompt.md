# Цель

Разработать расширенную программу курса по развитию компетенций для IT-проджект менеджеров уровня Middle и Senior, дополнив базовую 4-месячную программу Yandex актуальными навыками и компетенциями из предоставленных аналитических материалов.

# Формат возврата

Markdown-файл с названием "final_program_Middle_PM.md", содержащий:
- Полную исходную структуру курса Yandex без изменений
- Новые расширенные блоки с суффиксом "Расширенный" в каждом релевантном модуле
- Дополнительный Модуль 9 (при необходимости) для компетенций, не подходящих к существующим модулям
- Четкую визуальную идентификацию добавленного контента
- Тот же уровень детализации, что и в исходном курсе Yandex (включая описания тем, длительность модулей, практические задания, если они присутствуют в оригинале)

# Предупреждения

- Категорически запрещено удалять, изменять или перефразировать любой контент из исходной программы Yandex
- Строго соблюдать формат и стиль представления информации, используемый в исходном курсе Yandex
- Не дублировать информацию, которая уже присутствует в базовой программе
- Избегать добавления компетенций, которые не соответствуют уровням Middle/Senior
- Не создавать расширенные блоки там, где нет релевантной информации для дополнения
- Сохранять логическую последовательность и структурную целостность программы
- Не добавлять компетенции, специфичные только для Junior-уровня
- Обеспечить, чтобы все дополнения были практически применимыми и соответствовали реальным требованиям рынка IT-проджект менеджмента
- Расширенные блоки должны соответствовать по структуре и глубине детализации исходным блокам курса Yandex

# Контекст

Базовая программа курса находится в файле:
"""
<Replace this text with the YANDEX PM PROGRAM 2025 or upload a file>
"""

Источники для обогащения программы:
"""
<Replace this text with the NOTEBOOKLM SKILLS RF or upload a file>
<Replace this text with the NOTEBOOKLM SKILLS WORLD or upload a file>
<Replace this text with the GEMINI3PRO SKILLS WORLD or upload a file>
"""

Ассистент должен сначала тщательно изучить исходную структуру курса Yandex, включая формат представления информации, уровень детализации описаний, способ структурирования модулей и блоков. Затем проанализировать все существующие модули и блоки, систематически сопоставить компетенции из аналитических файлов с соответствующими разделами программы. Для каждого блока, который может быть обогащен, создается параллельный "Расширенный" блок с аналогичным уровнем детализации. Компетенции, не вписывающиеся в существующую структуру из 8 модулей, группируются в новый Модуль 9 с логичной внутренней структурой, соответствующей формату остальных модулей.
