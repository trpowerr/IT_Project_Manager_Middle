# 📚 Программа развития навыков IT-менеджера проектов

Привет! 👋 Это программа развития для менеджеров IT-проектов уровня Middle / Middle+, которая поможет систематизировать знания и восполнить компетенции до уровня Middle+ / Senior.

## 🎯 Цели и задачи

* **Синхронизация с рынком:** Добавление критических навыков, которые требуют работодатели в 2025–2026 годах: от работы с нейросетями до глубокой технической аналитики.
* **Middle Core:** Полное покрытие фундаментальных компетенций: управление поставкой, работа с командой и стейкхолдерами.
* **Senior Boost:** Внедрение стратегических блоков: юнит-экономика, управление портфелями, масштабирование процессов (SAFe) и оценка ROI от внедрения AI.

---

## 📂 Входные данные

Для работы использовался стек из 5 документов:

1. `yandex-pm-program-2025.md` — базовая структура курса и основные темы.
2. `Gemini3pro.-Navyki-IT-prodzhekt-menedzher-MIR.md` — аналитика глобальных трендов (Middle+ vs Senior).
3. `NotebookLM.-Navyki-IT-prodzhekt-menedzher-MIR.md` — международные стандарты (Agile, Scaling, Business Acumen).
4. `NotebookLM.-Navyki-IT-prodzhekt-menedzher-RF.md` — специфика российского IT-рынка (импортозамещение, таск-трекеры, SQL).
5. `prompt.md` — методологический каркас и правила расширения программы.

---

## 🛠 Как мы это делали (Process Workflow)

Процесс был разделен на 6 итераций, гарантирующих точность и полноту:

1. **Валидация:** Мы нашли в программе Яндекса 32 «точки вставки» для расширенной информации.
2. **Экстракция навыков:** Собрали единый реестр компетенций из рыночной аналитики (от управления конфликтами по Томасу-Килманну до контейнеризации Docker).
3. **Маппинг:** Каждый навык был привязан к конкретному модулю курса. Например, **SQL** отправился в метрики, а **SAFe** — в операционную основу.
4. **Генерация:** Мы написали прикладной контент для каждого блока, соблюдая лимит «5 буллетов» — только самая суть без воды.
5. **Интеграция:** Все новые знания были бесшовно вшиты в исходный файл с сохранением оригинальной структуры.
6. **Контроль качества:** Проверка на соответствие уровням (Middle/Senior) и актуальность инструментов.
