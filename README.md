# 📚 Программа развития навыков IT-менеджера проектов

Привет! 👋 Это программа развития для менеджеров IT-проектов уровня Middle / Middle+, которая поможет систематизировать знания и восполнить компетенции до уровня Middle+ / Senior.

## 🎯 О программе

**Продолжительность:** 6–8 месяцев  
**Цель:** Систематизация базовых знаний и восполнение компетенций до уровня Middle+ / Senior на основе мировых стандартов (PMBOK 7, PRINCE2, ITIL 4) и современных технологических трендов (AI, Cloud, FinOps).

## 📖 Как это появилось

Программа создавалась в несколько этапов:

1. **Базовая программа** — взял готовый курс «Мидл менеджер проектов» от Yandex как основу
2. **Обогащение** — с помощью различных LLM (Gemini, NotebookLM) проанализировал требования к навыкам IT-проджект менеджеров на международном и российском рынках
3. **Результат** — объединил всё в финальную расширенную программу с дополнительными модулями и темами

## 📁 Структура файлов

### `final_program_Middle_PM.md` ⭐
**Финальная программа развития** — основной файл с полной программой обучения. Содержит 9 модулей:
- Модули 1–8: базовые темы (операционная основа, работа с заказчиком, процесс, команда, метрики, UX/UI, DevOps, документация)
- Модуль 9: стратегическое лидерство (обзор Senior-компетенций)

Каждый модуль включает:
- Основные инструменты и подходы
- Расширенные инструменты (PMBOK 7, PRINCE2, AI, Cloud и др.)
- Темы модуля
- Расширенные темы для Middle+
- Практику и результаты

### `yandex-pm-program-2025.md`
**Исходная базовая программа** — курс «Мидл менеджер проектов» от Yandex. Содержит 8 модулей без расширенных разделов. Использовалась как основа для разработки финальной программы.

### `Gemini3pro. Навыки IT-проджект менеджер МИР.md`
**Матрица компетенций** — сравнительный анализ навыков Middle+ vs Senior по категориям:
- Soft Skills (мягкие навыки)
- Hard Skills (жесткие навыки)
- Технологии и инструменты
- AI (навыки работы с искусственным интеллектом)

Структурировано согласно международным стандартам (PMBOK, Scrum.org, Gartner).

### `NotebookLM. Навыки IT-проджект менеджер МИР.md`
**Навыки для международного рынка** — описание компетенций IT-проджект менеджера с акцентом на:
- Soft Skills / Power Skills
- Hard Skills
- Технологии и инструменты
- AI-компетенции

Включает разграничение уровней Middle и Senior.

### `NotebookLM. Навыки IT-проджект менеджер РФ.md`
**Навыки для российского рынка** — справочник компетенций с учетом специфики российского рынка:
- Российские инструменты (Kaiten, YouGile, Weeek)
- Требования ведущих работодателей (СБЕР, Яндекс, Ozon)
- Адаптация под локальные реалии

Структура аналогична международной версии, но с фокусом на российский рынок.

## 📄 Формат файлов

Все файлы представлены в формате **Markdown (.md)** для удобного чтения и редактирования.

---

💡 **Совет:** Начните с файла `final_program_Middle_PM.md` — там вся программа в структурированном виде. Остальные файлы помогут понять контекст и источники информации.
