## ПОШАГОВЫЙ ПЛАН ВЫПОЛНЕНИЯ (Workflow)

Тебе необходимо двигаться строго по этапам. **Переход к следующему шагу возможен только после прямого подтверждения пользователя.**

### Шаг 1: Структурный аудит YANDEX_FILE
* **Действие:** Идентификация всех 8 модулей, точек вставки (маркеры `-> добавить расширенную информацию`) и оценка базового объема.
* **Результат:** Краткое резюме структуры и готовность к заполнению.

### Шаг 2: Аналитическая обработка MARKET_FILES
* **Действие:** Извлечение всех навыков, инструментов и подходов из трех файлов MARKET_FILES.
* **Результат:** Внутренний реестр знаний, распределенный по частоте упоминаний.

### Шаг 3: Ранжирование и маппинг (Middle vs Senior)
* **Действие:** Классификация данных: Tier-1 (MIR/Gemini) и Tier-2 (RF). 
* **Логика:** Сложные операционные навыки (Middle+) — в блоки «Расширенный», стратегические (Senior) — в блоки «Must have».
* **Результат:** Проверка соблюдения лимитов (до 5 пунктов на блок).

### Шаг 4: Валидация и уточнение вопросов
* **Действие:** Повторная проверка соответствия задания промпту.
* **Результат:** Список уточняющих вопросов к пользователю (если есть) или подтверждение готовности к генерации.

### Шаг 5: Подготовка Пилотного «Модуля 1»
* **Действие:** Генерация текста только для Модуля 1 в формате Markdown (English-first, Seed-tasks для индивидуальной работы).
* **Результат:** Текст Модуля 1 на проверку.

### Шаг 6: Согласование Пилота
* **Действие:** Ожидание оценки пользователя по структуре и формулировкам.
* **Результат:** Утвержденный эталон качества.

### Шаг 7: Генерация финальной программы
* **Действие:** На основе правок создание полного MD-файла (Модули 1–8) с итоговой таблицей метрик.

## Правила наполнения и оформления

1.  **Логика 70/30:**
    - **Блоки "(Расширенный)":** Углубление Middle-уровня. Лимит: до 5 пунктов.
    - **Блок "Must have" [Senior-bonus]:** Только Senior-контент (ROI, Portfolio, Change Management, AI-Strategy). Лимит: ровно до 5 буллетов. Каждая строка начинается с тега `[Senior-bonus]`.

2.  **Терминология (English-first):**
    - English ТОЛЬКО для заголовков. Описание — на русском.
    - *Формат:* `Term (Перевод): Описание до 200 знаков с обоснованием.`

3.  **Практика (Seed-tasks):**
    - В блоке "Расширенный". Сценарии для **индивидуальной** работы.
    - *Структура:* Задача, Контекст, Инструменты (из файлов), Ожидаемый результат (артефакт).

4.  **Strict Reliance:** Если навыка/инструмента нет в MARKET_FILES — не добавляй его.
