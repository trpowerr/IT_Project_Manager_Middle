# Инструкция по наполнению модулей учебными материалами (Senior Level)

## 1. Подготовка исходного файла
Перед запуском генерации убедитесь, что исходный файл модуля размечен следующими тегами:
- `<tools>` — Список инструментов и подходов.
- `<themes>` — Список теоретических тем модуля.
- `<bonus>` — Блок Must have (Senior-бонусы).

## 2. Мастер-промпт для LLM
Скопируйте текст ниже и добавьте к нему содержимое вашего модуля:

"""
Действуй как экспертный ментор для IT Project Manager-ов уровня Senior. Твоя задача — наполнить учебный модуль материалами, используя предоставленную структуру.

### Алгоритм работы:
1. **Маппинг:** Сопоставь инструменты из тега <tools> с темами из тега <themes>. 
   - Не изменяй названия тем.
   - Не меняй порядок тем.
   - Не объединяй темы.
2. **Поиск (для каждого инструмента):** Подбери ровно 3 учебных материала:
   - **[Doc]** — Официальная документация, манифест или отраслевой стандарт.
   - **[Analysis]** — Глубокая аналитика, критический разбор "под капотом" или сравнительное исследование.
   - **[Case]** — Реальный кейс внедрения в крупной IT-компании (FAANG, тех-гиганты, крупные банки).
3. **Поиск (для блока Must have):** Подбери по 3 стратегических материала на каждую тему из тега <bonus>.

### Требования к материалам:
- **Никаких курсов:** Исключи любые обучающие курсы (Stepik, Coursera, Udemy и т.д.).
- **Прямые ссылки:** Ссылки должны вести сразу на целевой ресурс. Никаких редиректов через поисковики (google.com/search...).
- **Надежность:** Используй HBR, PMI, McKinsey, Gartner, Medium (только экспертные статьи), инженерные блоги (Netflix, Atlassian, Spotify).
- **Язык:** Ссылки могут быть на любом языке, но комментарии — строго на русском.

### Требования к комментариям:
Под каждой ссылкой напиши:
- **О чем:** Лаконичное описание содержания.
- **Senior-профит:** Почему это критически важно для уровня Senior (акцент на стратегии, рисках, архитектуре процессов или бизнес-результате).

### Формат вывода:
Выведи результат в одном блоке кода Markdown. Структура:
### [Номер]. [Название Темы из исходника]
#### Инструмент: [Название инструмента]
* [Тип] [Название ссылки](URL)
  * **О чем:** ...
  * **Senior-профит:** ...

[И так далее для всех элементов]

### Блок: Must have (Senior-bonus)
#### Тема: [Название бонусной темы]
* [3 ссылки с комментариями по той же структуре]
"""

## 3. Чек-лист проверки результата
- [ ] Количество тем в ответе строго соответствует количеству тем в исходнике.
- [ ] Все ссылки являются прямыми (не содержат google.com/search).
- [ ] В списке отсутствуют онлайн-курсы.
- [ ] Комментарии "Senior-профит" объясняют управленческую ценность, а не просто пересказывают статью.
